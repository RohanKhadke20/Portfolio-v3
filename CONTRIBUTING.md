# Contributing to Portfolio-v3

Thank you for your interest in contributing to the Portfolio-v3 project!

## Development Guidelines

1. **Architecture**:
   - Built with Vanilla HTML5, modern CSS3 (custom properties, responsive grid, glassmorphism), and Vanilla ES6+ JavaScript.
   - Zero external frontend frameworks or heavy dependencies required.
2. **Branching & Commits**:
   - Use descriptive feature branches (`feat/`, `fix/`, `docs/`).
   - Follow conventional commit standards (`feat:`, `fix:`, `refactor:`, `docs:`).
3. **Local Testing**:
   - Test responsive viewport behavior across mobile (<768px), tablet (768-1024px), and desktop (>1024px).
   - Ensure terminal CLI emulator commands function smoothly and return accurate responses.
   - Verify external hyperlinks and project assets load without 404s.
